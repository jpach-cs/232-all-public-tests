# CS232 Course Test Binaries

This repository contains compiled object files (`.o`) used for automated testing of programming assignments in the **CS232** course. 

## Structure
- Each lab assignment has its corresponding pre-compiled test object file located in its respective directory.
- These binaries are automatically generated and synchronized via GitHub Actions from our private test source repository.

## Usage
These files are automatically fetched and linked during the build and evaluation process within the student assignment templates. They are not intended for manual modification.
